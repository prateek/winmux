What the browser trees teach us

The live guest captures beside the pick show ancestry, folding and filtering. Tree Style Tab’s search uses the TST Tab Search helper; Sidebery’s filter is built in. The README records licences and the guest-only profile. No extension code implements WinMux.

His choice, recorded

On 2026-10-18 Prateek picked a numbers-only rail and a flat tree with proportional Column marks. Split and Column levels are independent workspace toggles. A window-row drop inserts a sibling in its actual parent, even while that parent is hidden.
