A recommendation to try

B, Columns as marks. Width-proportional marks retain the layout’s Column boundaries without adding five rows to this desk. Its rail answers which app is waiting in each workspace. A is the clearest model for learning Columns; C is the quietest, but its boundaries are easier to miss.

Tab groups use a tab glyph and a bracketed child rail. Splits use an orientation glyph and ordinary indentation. Floating windows have a separate group. The README gives the drag operation table, evidence and the feature draft that waits on a choice.
